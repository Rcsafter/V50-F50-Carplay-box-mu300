1确认型号与固件版本

版本号决定了你用哪一个 Root 包，选错了会失败。

1.1手机或电脑连上盒子的 WiFi

盒子的默认 WiFi 名称和密码贴在机器背面。

1.2浏览器打开 192.168.0.1

这是中兴原始后台。用背面标签上的密码登录。

1.3找到「系统版本」，把版本号记下来

一般形如 B22、B13 这样的短编号。截图存下来，等下选 Root 包要对照。

如果后台里一时找不到，也可以在「关于设备 / 设备信息」里翻，固件版本字段通常会带这个编号。

顺便确认机型

网盘里 E5、M8、mu300 是不同机器的镜像，不要混用。V50 / F50 属于 mu300 这一支。下载前先看清文件夹名，别拿 E5 的包往 V50 上刷。

2备份系统

工具包名字叫「一键刷分区、备份还原」，但你只需要用里面的备份。

这一步最容易出事：不要刷分区

网盘那个文件夹叫「一键刷分区、备份还原工具」，名字容易让人以为「先刷个分区再备份」。不是。

你只需要用它备份。里面的「刷分区」功能完全不用碰——原机分区是好的，刷分区动的是底层分区表，一旦中途出错，连备份都救不回来。

备份完也不需要「刷回去」，备份只是留一份保险，放着别动。

2.1下载并解压工具包

解压到一个路径没有中文、没有空格的位置，比如 D:\v50\。中文路径会让脚本找错文件。

2.2先看这个文件夹里的使用教程

原作者的规矩：每个文件夹用之前，都先看它自带的教程。工具版本会更新，界面可能和我写的不完全一样，以文件夹里的说明为准。

2.3运行备份，等它跑完

备份文件会自动生成在同一个文件夹里，命名形如 backup_xxxx。

跑完检查一下：大约 73 个文件、合计 5.28 G。数量和体积对得上，说明备份是完整的。

把这堆文件收好

backup_xxxx 整个文件夹拷一份到移动硬盘或另一台电脑。它就是你唯一的后悔药，别留在原机要刷的那块盘上。

3一键 Root

顺序是反的：先开脚本，再插盒子。这一步照着做，基本一次过。

先理解为什么顺序是反的

这个 Root 脚本的原理是：脚本先在电脑上守着一个 USB 端口等设备出现，设备一插上就立刻抓握手。如果你先把盒子插上再运行脚本，盒子会先被 Windows 当成普通设备枚举掉，脚本就抓不到了，表现为「脚本一直等，插了也没反应」。

装驱动→线插电脑→运行脚本→再插盒子

3.1解压对应版本的一键 Root 工具

按第 1 步记下的版本号选文件夹，比如 B22 就用 一键Root_B22。

驱动文件就在这个 Root 工具包里，不用另外去网上找驱动。

3.2安装刷机驱动

在 Root 工具文件夹里找驱动安装程序（.exe，或带 .inf 的驱动目录），双击安装，一路下一步。

如果弹出「Windows 已保护你的电脑」，点更多信息 → 仍要运行。这类第三方驱动没有微软签名，属于正常情况。

装完不放心可以在设备管理器里看一眼有没有黄色感叹号。

3.3把 USB 数据线插到电脑后面的接口

台式机请插主板后置 USB 口，不要用前面板，也不要用 USB 延长线或 Hub。前面板供电和信号都弱，刷机中途掉线是致命的。

笔记本就直接插机身上的口，别接扩展坞。

此时线只插了电脑这一头，盒子那头先空着。

3.4运行「[直接插电] 一键 Root」脚本

双击运行，看到脚本提示「等待设备 / Waiting for device」这类字样，说明它已经在守端口了。

建议右键以管理员身份运行，避免权限不足导致驱动加载失败。

3.5现在才把线插到盒子上

脚本在等的时候，把数据线另一端接到盒子。脚本会自动往下跑，屏幕上开始刷字符。

这时候手不要动，等它自己跑到结束提示（通常是 Done / 按任意键退出）。

一定要选带「无线 ADB」的 Root 包

工具包里可能有多个 Root 包，优先选带无线 ADB 的那种。原因很实际：有线 ADB 经常在后面的步骤里认不到设备（驱动、端口、线材都会影响），有无线 ADB 就可以直接靠 WiFi 连，省掉一大堆折腾。

如果只有有线包，也不是不能用，只是后面「装面具」那一步失败的概率会高一些。

成功的样子

脚本跑完不报红字，盒子重启一次，WiFi 能重新连上，就说明 Root 装进去了。真正的验证在第 7 步。

4装高级后台

一个网页版的管理界面，后面装插件、看 Root 状态都在这里。

4.1安装 UFI-TOOLS 一键安装器

从网盘下载 UFI-TOOLS一键安装器1.9.2_x64，解压后运行安装程序。

4.2盒子用数据线连着电脑，打开软件点「一键安装」

软件会自己找到设备并装上「高级后台」。装完盒子可能需要重启一次。

4.3浏览器打开 192.168.0.1:2333

这就是高级后台。登录用的两样东西不一样，别搞混：

字段值
UFI 口令admin（固定）
密码机器背面标签上那串（和你登录 192.168.0.1 的密码是同一个）

5装面具 Magisk

用肥猫助手推一个 apk 进去。这一步 90% 的失败都是路径里有中文。

5.1把面具 apk 挪到纯英文路径

在第 3 步的 Root 工具文件夹里找到面具安装包（*.apk），复制到类似 D:\apk\magisk.apk 这种位置。

路径里不能有中文，也不能有空格；文件名里的中文后缀也去掉，只留 magisk.apk。

原因：肥猫助手是把这串路径原样交给盒子里的命令行执行的，遇到中文或空格会被截断，然后就报「文件不存在」——但文件其实在。

5.2打开肥猫助手，输入 3 回车

进入安装 APK 的功能。

5.3再输入 A 回车

选择安装模式（A 一般对应「安装到设备」）。

5.4粘贴 apk 的完整路径，回车

直接把 D:\apk\magisk.apk 粘进去（在资源管理器地址栏里复制完整路径最稳）。

安装成功的提示会出现在助手窗口里。装完去盒子的应用列表里应该能看到「Magisk」。如果没看到，先别急着重复装，用第 6 步的投屏看一眼，有时是桌面没刷新。

6投屏里修复面具

面具装上了还没生效，要进它自己的界面点一次修复。

6.1肥猫助手输入 5 回车

这会打开投屏工具，电脑上能看到盒子的画面。

6.2在投屏画面里从下往上滑

打开盒子的应用抽屉，找到「Magisk / 面具」图标，点进去。

6.3点「修复」，确认

面具会提示需要修复运行环境，点确认/修复，让它自己跑。

这一步会往系统里写文件，可能需要几十秒，别中途关掉。

做完的样子

面具首页显示版本号、不再是「需要修复」的红色提示，就说明生效了。真正的 Root 验证在下一步。

7验证 Root 与关掉自动更新

两件事一起做：确认真的 Root 了，并且防止系统自己升级把你刷的东西覆盖掉。

7.1回高级后台，打开「插件」

地址还是 192.168.0.1:2333，用刚才的口令和密码登录。

7.2导入检测脚本

把网盘里那个 TXT 格式的检测脚本直接拖进插件区域，然后点提交。

这个脚本的作用是「查询是否已 Root」和「禁用系统更新」，两个功能都在里面。

7.3同时添加「系统切换器」插件

同一个页面加上系统切换器插件。它是 Android 这边「切到 OpenWrt」的开关——刷完之后就是从这里进新系统。

两个方向、两个入口，别搞混：

  • Android → OpenWrt：用这个插件，在高级后台里点一下
  • OpenWrt → Android：用 OpenWrt 后台自带的功能，不在这个插件里

两个系统是并存的，不是覆盖关系：切过去之后 Android 那套装的东西还在，随时能切回来。想用哪个就待在哪个，这也是它最值钱的地方——刷崩了有退路。

插件下载地址在 https://pan.quark.cn/s/05c6a09772ad（提取码 HnJc）。

7.4打开「高级功能」→ 查询 Root 状态与 FOTA 更新状态

两个状态都显示成功/已 Root/已禁用，就可以往下走了。

确认成功之后，把「高级功能」关掉（移除），然后重启盒子让它生效。这个开关长期开着会干扰后续操作。

不要把「高级功能」一直留着

原作者特别强调了这一点：验证完就移除、重启。留着不关，会在装 OpenWrt 的时候产生冲突，表现为安装器连不上设备或写一半失败。

8装 OpenWrt

到这里 Android 侧的准备全部完成，剩下的交给 OP 系统安装器。

8.1下载 OP 系统安装器

就在同一个网盘里（OP系统安装器/ 文件夹），不用另外找。解压到纯英文路径。

8.2下载对应机型的 OpenWrt 镜像

同一个网盘，看清文件夹：

文件夹对应机器
mu300V50 / F50（你这台）
E5E5 机型，不要混用
M8M8 机型，不要混用

原作者更新节奏不固定，E5、M8 可能已经有新版而 mu300 还在编译。把网盘地址收藏起来，隔几天看一次；如果暂时没有 mu300 的包，就等，不要拿别的机型的镜像凑。

8.3用安装器写入

盒子连电脑，打开安装器，选好镜像，按界面提示开始写入。

写入过程会重启几次，全程不要拔线、不要断电。看到完成提示再拔。

8.4第一次切进 OpenWrt

写入完成后如果开机还是 Android 界面，不是失败——去高级后台（192.168.0.1:2333）的「系统切换器」插件点一下，切到 OpenWrt。

切换会重启，断网几十秒，正常。等 WiFi 名字变过去再连。

刷完先别急着拆

第一次进 OpenWrt 比较慢（1~3 分钟），盒子会自己重启一两次。等它的 WiFi 名字变成 OpenWrt 之类的默认名，再去连。

9进系统后的第一件事

三分钟做完，后面 AI 接管会顺利很多。

9.1连上盒子 WiFi，打开 192.168.1.1

新刷的 OpenWrt 默认网段通常是 192.168.1.1，和原来中兴后台的 192.168.0.1 不一样，别搞混。

9.2设置 root 密码

首次登录没有密码，进去第一件事就是设一个。这个密码后面 SSH、控制台都要用。

9.3让它能上网

插上 SIM 卡，在「网络」里确认 5G/4G 接口拿到了地址。能打开任意网页就说明通了。

这一步不通，后面所有配置都是白做——先解决联网。

9.4看一下蓝牙

镜像自带的蓝牙有时是坏的（车机连不上、CarPlay 起不来都跟它有关）。原作者的做法是让 AI 检查修复，本仓库也把这个检查放进了体检脚本，所以现在不用管，下一步一起处理。

10申请一个免费域名

不是图好看。不做这一步，车机很可能根本打不开你的页面。

为什么非要用域名

特斯拉车机不认私网 IP。你在车里输 192.168.x.x，它直接拦掉；输 100.96.x.x 这类运营商级 NAT 段，它会弹安全警告。这两类地址在它的规则里都不算“正常网址”。

更根本的一点：证书没法签给 IP。Let's Encrypt 不给私网地址签发，所以只要用 IP 访问，永远显示「不安全」——换什么证书都一样。

域名一次解决两件事：车机认它是正常网址，证书也名副其实。这就是为什么这一步不能省。

10.1注册 DuckDNS（免费，3 分钟，不用备案）

DuckDNS 不单独注册账号，是借 GitHub 登录的。所以顺序是：先有 GitHub 账号，再拿它登录 DuckDNS。

  • 没有 GitHub 账号：打开 https://github.com/signup，用邮箱注册一个（用户名、邮箱、密码三步，收一封验证邮件即可；不想填真名，随便填也行）。
  • 打开 https://www.duckdns.org/，点页面上的 sign in with GitHub，登录后允许授权（只读取基本资料，不用给手机号）。
  • 回到首页，在顶部 subdomain 输入框里填一个没被占的前缀，比如 v50tesla，点 add domain。
  • 页面列表里会出现 v50tesla.duckdns.org，同一行下面那串 token=xxxxxxxx-xxxx-xxxx-... 就是它的密码，复制下来，别发群里（以后想再看，首页顶部一直显示）。

也可以用 Google 账号登录，效果一样；国内 GitHub 访问不稳的话再考虑那条路。

不用买域名、不用实名、不用备案。DuckDNS 的规则是「30 天完全没更新就回收」，下一步的脚本会在盒子上装一个每天更新一次的定时任务，所以放着不管也不会过期。

10.2让盒子把这个域名解析到自己

一条命令，把上面两样填进去：

DUCKDNS_SUB=v50tesla DUCKDNS_TOKEN=你的token \
  sh install.sh --module domain

交给 AI 的话只说一句“帮我配域名，前缀是 xxx，token 是 xxx”，它会自己跑这个模块。

这一步实际上做了四件事：

动作目的
在 DuckDNS 上把 A 记录指到盒子让服务商那边「域名 ↔ 盒子」的对应关系也是对的
dnsmasq 里加 address=/域名/盒子IP车里一查这个域名就返回盒子地址，不依赖外部 DNS
屏蔽这个域名的上游 AAAA 查询不屏蔽的话手机会先试 IPv6，等超时再回来，体感就是「页面打开很慢」
acme.sh 签 Let's Encrypt 证书用 DNS-01 方式验证，不占 80 端口，也不需要盒子有公网 IP

10.3验证两件事

① 在连着盒子 WiFi 的手机/电脑上查一下解析：

nslookup v50tesla.duckdns.org

正常应该返回盒子自己的地址（192.168.1.1 或 100.96.0.1），而不是某个公网 IP。

② 浏览器（或车机）打开 https://v50tesla.duckdns.org/：地址栏是锁头、没有红色警告，就是成了。

如果证书还没签下来（命令行里会写明失败原因），先跑 sh install.sh --module tls 用自签顶上——功能照常，只是还会提示不安全；等签下来再跑一次就换成正式证书。

把这些存成书签，以后不用再记 IP。

用 IP 还能打开吗

能，局域网里 IP 和域名指向同一个盒子，功能完全一样。区别只在「能不能过车机和证书的检查」——所以车里、手机上请养成用域名的习惯。

换了网段 / 盒子地址变了

这个域名的 A 记录指向的是内网地址，本来就是给车里用的，外面打不开（要在外面看，得另装 tunnel 模块，需要你自己的隧道凭据）。

如果改了盒子网段（比如 192.168.1.1 改成 100.96.0.1），重跑一次 sh install.sh --module domain 就会把 dnsmasq 和 DuckDNS 两处的地址一起更新，不用手工改。

12出问题了怎么救

按严重程度排，从轻到重。

情况一：OpenWrt 进不去，但还能连上 WiFi

  • 先等 3 分钟，首次启动慢是正常的。
  • 换 192.168.1.1 和 192.168.0.1 都试一下。
  • 手机连 WiFi 后看有没有拿到 IP，拿不到说明 DHCP 没起来。

情况二：想回 Android 用，或者 OpenWrt 起不来

在 OpenWrt 后台自带的功能里切，不要去找那个插件——插件只存在于 Android 系统里，你人在 OpenWrt 里是点不到它的。这一步最容易搞反。

入口在 OpenWrt 后台的菜单里，不同镜像位置略有差别，一般叫「系统切换 / 切换到 Android / Switch」，翻一下 LuCI 菜单就能看到。点完盒子重启，几十秒后回到 Android，原来的中兴后台 192.168.0.1 也就回来了。

OpenWrt → AndroidOpenWrt 后台自带的切换功能（LuCI 菜单里）
为什么值得留着两个系统

两边互不覆盖，Android 那套（中兴后台、原厂功能）和 OpenWrt 那套（投屏、共享、控制台）都完整保留，想用哪个就待在哪个。哪天 OpenWrt 配坏了，切回去照样能上网、能开热点，不至于手里一块砖。

切换会重启并断网几十秒，别在导航或通话中途切。

情况三：刷坏了，连 WiFi 都没有

回到第 2 步的 backup_xxxx 备份，用「备份还原」工具还原整机。前提是备份完整（73 个文件 / 5.28 G）。

那就只能走展锐平台线刷（需要专用工具和固件包），一般个人做不到。所以第 2 步不能省——这也是整篇教程里唯一不能跳的一步。

13名词与常见报错

看不懂的词查这里。

刷分区是什么？为什么我不需要

分区是机器存储被切成的若干块（系统区、数据区、引导区等）。「刷分区」是重写分区表，属于底层操作，失败就没法开机。

原机分区本来就是好的，刷 OpenWrt 用的是安装器自己处理，你不需要手动碰分区。工具包虽然叫「一键刷分区、备份还原」，你只用备份那一半。

Root、面具（Magisk）、高级后台分别是什么
  • Root：拿到 Android 的最高权限，没有它装不了下面的东西。
  • 面具 / Magisk：管理 Root 权限的工具，也用来藏 Root。刷 OpenWrt 需要它配合。
  • 高级后台：一个网页界面（192.168.0.1:2333），用来装插件、看 Root 状态、开关系统更新。
为什么非要「带无线 ADB」的 Root 包

ADB 是电脑连 Android 调试的通道。有线 ADB 依赖 USB 驱动和线材，在刷机这种驱动刚装完、线材质量未知的环境下经常连不上。

无线 ADB 走 WiFi，绕开了 USB 这一整条链路，成功率明显高。装面具那步如果卡住，先怀疑这里。

OpenWrt 装好之后，原来的 4G/5G 上网还在吗

在。镜像自带调制解调器支持，插上 SIM 卡配好接口就能用。但网段变了（192.168.1.1），原来存的 192.168.0.1 书签都会失效。

刷完能一直待在 OpenWrt，不回 Android 吗

可以，而且大多数人就是这么用的。两个系统是并存的，开机待在哪个由你上次切到哪决定，不需要每次开机都选。

要回 Android：在 OpenWrt 后台自带的切换功能里切；要从 Android 回 OpenWrt：用高级后台的「系统切换器」插件。两边各有各的入口，别在同一个地方找两个方向。

整个流程大概多久

备份 10~20 分钟（取决于盘的速度），Root 和装面具 20 分钟左右，装 OpenWrt 10 分钟，AI 配置 20~30 分钟。第一次做留够两小时比较稳，中间别赶时间。
