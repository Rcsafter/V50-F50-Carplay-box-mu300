# V50 车载盒子 · 一键安装

把**中兴 V50 / F50**（同一台机器，内部型号都是 `MU300`，芯片展锐 UMS9620）这类 5G CPE
刷成 OpenWrt 之后，用一条命令配成车上真正能用的娱乐盒子：

- 🎬 **CarPlay / 投屏**：车机浏览器打开盒子地址就能看画面（依赖镜像自带的 DashPlay）
- 🍿 **车内共享**：手机/车机直接播 U 盘或内置盘里的电影，支持拖动进度条
- 📱 **手机控制台**：流量、短信、温度、在线设备一屏看完
- 🔔 **流量短信**：开机自动发「查流量」，把运营商回复推到微信（可选）
- 🌐 **免费域名**：DuckDNS 一个免费二级域名 + 本地解析。**特斯拉车机不认 `192.168.x.x` / `100.96.x.x`，
  这一步不做，车机大概率打不开页面**
- 🔒 **HTTPS**：域名 + Let's Encrypt，浏览器和车机都不再警告

> 本仓库**不包含**刷机镜像和第三方工具，只做「刷好系统之后」的配置与自检。
> 刷机部分请看 [docs/index.html](docs/index.html) 里的新手教程，工具来源与致谢见[第六节](#六致谢与来源)。

## 一、最快路径：让 AI 帮你装

把下面这段整个复制给你的 AI（WorkBuddy / Claude / ChatGPT 等**能连 SSH 的 Agent**），
把 `<仓库地址>` 换成实际地址（或直接把 zip 发给它）：

```text
请读这个仓库里的 AI-INSTALL.md，帮我配置车载盒子：
<仓库地址>

先只做第 0 步体检并把报告发我确认，不要动任何配置。确认后按模块一步步来，
每步做完把校验结果发我。遇到标记为「禁止」的操作一律停下问我。
另外请检查并修复蓝牙，确认车机能正常连上。

我要在车里用域名访问（特斯拉不认内网 IP），请帮我配一个 DuckDNS 免费域名，
token 我一会儿单独给你。
```

AI 会依次做：连 SSH → 跑体检 → 备份 → 按模块配置 → 逐项校验。
每个模块都是**幂等**的，装过再跑不会重复改。

> 前提：盒子已经刷好 OpenWrt 并能 SSH。还是 Android 的先看 [刷机教程](docs/index.html)，
> 那部分必须人在电脑前操作（插 USB、装驱动、跑脚本），AI 帮不了。

## 二、手动三条命令（给会 Linux 的人）

盒子上开 SSH（默认 `root@100.96.0.1`，密码在机器背面或你自己设的），然后：

```sh
# 1. 拉代码（把 <你的账号> 换成实际仓库；盒子没装 git 就在电脑上 scp 上来，或用发来的 zip）
wget -O v50-box.tar.gz https://github.com/<你的账号>/v50-box/archive/refs/heads/main.tar.gz
tar xzf v50-box.tar.gz && cd v50-box-main

# 2. 只体检，不改任何东西
sh install.sh --check

# 3. 按需安装（不带参数 = 逐项询问；--all = base domain share tls dashplay hover）
sh install.sh --all
```

## 三、装什么由你选

不带参数运行安装器，它会**逐项问你要不要装**，回车就是跳过，不想要的功能完全不影响 DashPlay：

| 模块 | 功能 | 谁做的 | 值不值得装 |
|---|---|---|---|
| `base` | 时区、日志、主机名、`/etc` 备份 | 本仓库 | 建议装，其他模块都靠它 |
| `domain` | **DuckDNS 免费域名 + 本地解析 + Let's Encrypt 证书 + 保活** | 本仓库 | **车机要能用就必须装** |
| `share` | 车内共享，手机车机播盘里的电影（可拖进度条） | 本仓库 | 车上放个 U 盘就有用 |
| `tls` | 把证书接到路由后台/共享上，不再显示「不安全」 | 本仓库 | 跟着 `domain` 装 |
| `dashplay` | 投屏主体，这里只设开机自启 | **抖音「一只小黑狗」** | 镜像自带才有 |
| `hover` | 车机画面右下角一个可拖动圆钮，点开看视频 | 本仓库 | 想边开车边看视频就装 |
| `traffic` | 开机自动发「查流量」，回复推到微信 | 本仓库 | 在乎流量就装（要花短信费） |
| `tunnel` | cloudflared 挂公网域名，外地也能看 | 本仓库 | 需要自己的域名和凭据 |
| `ai` | 助手进程与密钥权限健康检查 | 本仓库 | 配了 AI 助手才需要 |

```sh
sh install.sh --list          # 看完整清单
sh install.sh                 # 逐项询问（推荐）
sh install.sh --all           # 只装免凭据、不花钱的那几项
```

> `--all` = `base domain share tls dashplay hover`。`traffic`（要花短信费）、`tunnel`（要凭据）、
> `ai`（要有助手）必须你明确指定，安装器不会替你勾。
>
> `domain` 需要一个免费的 DuckDNS token（注册 3 分钟，不用备案）。没给 token 时这个模块会自己跳过，
> 后面的 `tls` 退回自签 —— 功能一样，只是浏览器仍会提示「不安全」。补装方式见[第四节](#四装完你能访问什么)。

## 四、为什么必须要一个域名

**特斯拉车机不认私网 IP。** 浏览器里输 `192.168.x.x` 会被直接拦；输 `100.96.x.x`（CGNAT 段）会弹安全警告。
而且 Let's Encrypt 不给私网 IP 签证书 —— 所以只要用 IP 访问，永远过一个「不安全」的页面。

一个免费 DuckDNS 域名同时解决两件事：

| 做法 | 命令 |
|---|---|
| 注册前缀（3 分钟，不用备案不用买） | 打开 `https://www.duckdns.org/`，填前缀，复制 token |
| 让盒子接管这个域名 | `DUCKDNS_SUB=前缀 DUCKDNS_TOKEN=token sh install.sh --module domain` |
| 把证书接到各项服务 | `sh install.sh --module tls` |

`domain` 模块会自动做四件事：DuckDNS 记 A 记录、dnsmasq 把域名解析到盒子自己
（**不依赖外部 DNS，断网也能解析**）、屏蔽该域名的上游 AAAA（否则手机会先试 IPv6 卡半天）、
acme.sh 用 DNS-01 方式签 Let's Encrypt 证书（不占 80 端口，也不需要公网 IP）。
另外加一条每天 04:17 的 cron 保活 —— DuckDNS 的免费域名 30 天没更新会被回收。

配好之后所有入口都用域名（把 `你的域名` 换掉即可）：

| 用途 | 地址 | 说明 |
|---|---|---|
| 路由后台 | `https://你的域名/` | LuCI |
| 手机控制台 | `https://你的域名:8444/` | 需登录；这是自建控制台，镜像默认只有 `http://IP:8082` |
| 车内共享 | `https://你的域名:8443/` | 看电影、下文件，支持拖进度条 |
| 投屏 / 车机页面 | `https://你的域名:18443/` | 镜像自带 DashPlay 才有 |
| 盒子设置 | `http://你的域名:18080/` | DashPlay 自己的服务，只有明文 |

> 这个域名只在车里有效（A 记录是内网地址），外面打不开。要在外面看，装 `tunnel` 模块走隧道。
> 改了盒子网段后重跑 `--module domain` 即可，dnsmasq 和 DuckDNS 两处地址会一起更新。

## 七、注意

- **刷机有风险**：变砖只能靠备份分区救回，务必先备份（教程第 2 步）。
- **双系统是并存的**：Android 与 OpenWrt 互不覆盖，想用哪个待哪个。
  切到 OpenWrt 用高级后台的「系统切换器」插件；切回 Android 用 **OpenWrt 后台自带的切换功能**——
  两个方向两个入口，不在同一个地方。
- **流量要钱**：查流量短信一条约 0.1 元，脚本有 6 小时去重；不用可以不加这个模块。
- **行车安全**：副驾/乘客操作，行驶中不要点屏幕。
- **别外传自己的密钥**：域名 token、隧道凭据、root 口令都不要提交到仓库。
